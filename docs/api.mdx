# API

The Mention backend is an Express 5 application served primarily from
`https://api.mention.earth`. The apex host reaches the same process for
ActivityPub, OG shells, and static web proxying.

This page describes route families and stable operational contracts. Individual
controllers remain authoritative for endpoint-specific request bodies and
response shapes.

## Authentication

Authenticated API routers accept an Oxy bearer token or a valid Mention MCP
JWT. Public read routers may attach optional viewer identity to calculate
visibility and viewer state. Mutations require identity in their mount or
handler.

Post responses are hydrated by `PostHydrationService` and use contracts from
`@mention/shared-types`. Oxy's user object is the canonical post-author shape.

## Operations

| Method | Path | Access | Contract |
| --- | --- | --- | --- |
| GET | `/health/live` | Public | `200` while the process can answer HTTP |
| GET | `/health/ready` | Public | `200` only after startup, migrations, and PostgreSQL; otherwise `503` |
| GET | `/internal/metrics` | Service-only | Prometheus output after network and bearer-token checks |
| POST | `/telemetry/web` | Trusted browser origin | Bounded web-vitals/runtime batch; returns `204` |

A ready response reports the runtime phase and PostgreSQL, migration, and Redis
states. Redis can be `degraded` without failing HTTP readiness.

Metrics use normalized route templates and bounded labels. The service does not
expose user IDs, post IDs, raw paths, query values, tokens, or private content
as metric labels.

Cursors are opaque to clients.

## Search and statistics

`GET /search` searches only published, visible posts. It uses PostgreSQL
full-text search — a generated `tsvector` column queried with
`websearch_to_tsquery('english', …)` — a minimal projection, a bounded
execution time, and an opaque, versioned cursor over `(createdAt, id)`.

Authenticated statistics routes:

| Method | Path |
| --- | --- |
| GET | `/statistics/user` |
| GET | `/statistics/post/:postId` |
| GET | `/statistics/followers` |
| GET | `/statistics/engagement` |
| GET | `/statistics/weekly-summary` |
| POST | `/statistics/post/:postId/view` |

The public activity route is
`GET /statistics/user/:userId/activity`.

## MCP OAuth and account bundles

OAuth routes are mounted outside the main API authentication wall. Approval
still authenticates the Oxy user directly:

| Method | Path | Access |
| --- | --- | --- |
| GET | `/.well-known/oauth-authorization-server` | Public |
| GET | `/.well-known/oauth-protected-resource` | Public |
| POST | `/mcp/oauth/register` | Public |
| GET | `/mcp/oauth/authorize` | Public |
| POST | `/mcp/oauth/approve` | Oxy user |
| POST | `/mcp/oauth/token` | Public |
| GET | `/mcp/bundles/link/preview` | Public |

Authenticated users manage connections through `/mcp/connections`. Bundle
members and active-account selection use `/mcp/bundles/accounts`,
`/mcp/bundles/me`, `/mcp/bundles/link-token`,
`/mcp/bundles/link/complete`, and `/mcp/bundles/active`.

The MCP resource and JWT audience are exactly `https://mcp.mention.earth`
without a trailing slash. Unauthenticated MCP requests receive a bearer
challenge.

## Request behavior

- JSON request bodies are limited to 1 MiB, including ActivityPub JSON types.
- Pagination and error bodies are endpoint-specific; do not assume one global
  envelope.
- Feed and search cursors are opaque and must be returned unchanged.
- API rate limiting excludes the apex browser asset plane.
- Structured request logs include a request ID, normalized route template,
  duration, and result without secrets or private payloads.
