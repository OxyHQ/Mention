# Mention

Mention is a cross-platform social application with four Bun workspaces:

| Workspace | Responsibility |
| --- | --- |
| `@mention/frontend` | Expo 56 app for iOS, Android, and web |
| `@mention/backend` | HTTP API, Socket.IO, jobs, feeds, and federation |
| `@mention/shared-types` | Shared TypeScript request and response contracts |
| `@mention/mcp` | Authenticated remote MCP tools and local transports |

The frontend uses React Native 0.85, React 19, Expo Router, Bloom,
NativeWind/Tailwind, TanStack Query, Zustand, Socket.IO, and lazy-loaded
Syra/LiveKit room support. The backend uses Express 5, PostgreSQL through
Drizzle ORM, Valkey-compatible Redis clients, BullMQ, Socket.IO, Zod, and
Prometheus instrumentation.

## Data ownership

- **Oxy** is authoritative for users, authentication, profile identity, blocks,
  restrictions, and the social graph.
- **Mention PostgreSQL** is authoritative for posts, feeds, engagement,
  notifications, Mention mutes, federation records, and MCP connection data.
- **MTN** appends verifiable signed records for eligible local writes. It does
  not replace the application's PostgreSQL read model.
- **External connectors** isolate ActivityPub and optional AT Protocol behavior
  from post creation and feed code.

`PostHydrationService` is the single backend authority for post DTOs. It emits
the canonical Oxy user shape rather than an app-specific identity adapter.

## Request flow

```text
Expo app ── REST / Socket.IO ──> Mention backend ──> PostgreSQL
                                     │   │
                                     │   ├──> Valkey: cache, queues, locks, pub/sub
                                     │   └──> Oxy: identity and graph
                                     │
Fediverse servers ── ActivityPub ────┤
MCP clients ── OAuth + HTTP ──> separate MCP service ──> backend API
```

## Production surfaces

| Surface | Purpose |
| --- | --- |
| `api.mention.earth` | API backend on AWS ECS |
| `mention.earth` | Federation endpoints, OG pages, and proxy to the static web app |
| `mcp.mention.earth` | Separate MCP ECS service |
| `mention-frontend.pages.dev` | Static Expo web origin |

The apex and API host reach the same backend. Protocol routers are mounted
before the apex proxy, so signed ActivityPub requests are handled directly.
AWS is the only application runtime deployment target.

## Health and observability

- `/health/live` is process liveness.
- `/health/ready` requires startup, schema migrations, and PostgreSQL.
- Redis/Valkey is reported as degraded without making HTTP readiness fail.
- `/internal/metrics` is protected by a service token and network restriction.
- `/telemetry/web` accepts bounded Core Web Vitals and browser runtime events.

Request metrics and structured logs use route templates and bounded labels.
Tokens, private content, request bodies, raw query values, and user IDs do not
belong in metric labels.
